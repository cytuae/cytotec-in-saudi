# Cytotec in Saudi

موقع عربي توعوي (Next.js App Router) حول سايتوتك والميزوبروستول في السياق السعودي.

## التشغيل

```bash
npm install
npm run dev
```

## البناء

```bash
npm run lint
npm run build
```

## متغيرات البيئة

انسخ `.env.example` إلى `.env.local`:

```bash
NEXT_PUBLIC_WHATSAPP_NUMBER=971547952044
```

الرقم يظهر في روابط `https://wa.me/971547952044` مع رسالة الاستشارة الجاهزة.

## النشر على Vercel

1. اربط المستودع بـ Vercel.
2. أضف `NEXT_PUBLIC_WHATSAPP_NUMBER` إن رغبت.
3. الدومين النهائي المتوقع: `https://cytotec-in-saudi.com`.

## ملاحظات تحريرية

- المحتوى للتوعية العامة فقط.
- لا أسعار ثابتة مخترعة، ولا ادعاء توفر/ترخيص/أصالة بلا دليل.
- لا جرعات شخصية ولا أطباء أو تقييمات مختلقة.
